# Data

The dataset is not stored in this repository.

1. Download **total-tree-population.csv** from the Dublin City Council tree dataset on Smart Dublin: https://data.smartdublin.ie/dataset/tree-dcc
2. Save it in this folder as `data/total-tree-population.csv`.

The notebook and the script both read it from here. The data is published by Dublin City Council under the Smart Dublin open data terms.
